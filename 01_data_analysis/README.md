# Data Analysis

Introduction to data manipulation, analysis, and visualization using Python.

This section introduces the main tools used to inspect, transform, summarize, and visualize datasets before applying machine learning techniques.

## Libraries

### NumPy

Used for numerical computation and array-based operations.

Main concepts:

* Arrays
* Numerical operations
* Mathematical functions
* Data manipulation

### Pandas

Used for structured data manipulation and analysis.

Main concepts:

* `Series`
* `DataFrame`
* Data selection
* Filtering
* Aggregation
* Statistical summaries
* Dataset transformation

### Matplotlib

Used for graphical data visualization.

Main concepts:

* Plots
* Charts
* Labels
* Axes
* Visual representation of datasets
